Dirichlet Thompson Tree Search

A math-first explanation of Scacchi's lightweight tree, its bottom-up message passing, and the targets returned to the network.

The search represents unresolved state and action values as learned Dirichlet beliefs over loss, draw, and win. Exact terminal and solved results live in categorical outcome/distance sidecars. A simulation walks unresolved edges by Thompson sampling, evaluates one frontier edge, and repairs every node on the path back to the root.

The central idea: an unresolved edge stores the latest repaired Dirichlet message; it does not keep adding leaf evidence. A separate structural count controls prior mixing. Once an edge is categorical, its exact sidecar—not an artificially concentrated alpha—owns its semantics.

1. Network beliefs

At state s, the network predicts a policy together with one state Dirichlet and one Dirichlet for every action:

\pi_\theta(a\mid s), \qquad V_s=\alpha_\theta^V(s), \qquad Q_{s,a}=\alpha_\theta^Q(s,a).

A Dirichlet parameter vector \alpha represents uncertainty about an outcome distribution:

\phi\sim\mathrm{Dirichlet}(\alpha), \qquad \mu(\alpha)=\mathbb E[\phi] =\frac{\alpha}{\sum_z\alpha_z}.

The outcomes are ordered as (L,W) or (L,D,W). Search compares samples with the same utility everywhere:

U(\phi)=\phi_W-\phi_L.

1.1 Player perspective

Values belong to the player to move at their node. Moving a value to the opponent's perspective reverses loss and win:

\mathrm{flip}(x_L,x_D,x_W) =(x_W,x_D,x_L). \mathrm{Align}(x;p\to q)= \begin{cases} x,&p=q,\\ \mathrm{flip}(x),&p\ne q. \end{cases}

Every child-to-parent message is aligned before it is stored.

2. A compact tree layout

The equations use separate symbols for separate meanings, but the tree does not need one permanent array for every symbol. Its storage follows the state of each node and edge. When an unresolved object becomes categorical, information that will never be read again is overwritten in place by the exact certificate.

The tree has no nested NodePosterior. It stores the following arrays directly:

Physical slot Unresolved interpretation Categorical interpretation
H_{s,a} · float [A,O] Network Q_{s,a} until repaired, then the latest message B_{s,a} Last learned alpha, retained only while an unresolved parent needs its concentration for the numeric cache mixture
V_s · float [O] Fixed network value prior Unused by search after the node becomes absorbing
C_s · float [O] Current repaired node cache Unused; the exact node certificate owns the value
z_{s,a} · int8 [A] \bot Exact edge outcome L,D, or W
d_{s,a} · int32 [A] Structural count R_{s,a} Certified edge distance \tau_{s,a}
z_s · int8 \bot Exact node outcome
d_s · int32 Total structural support n_s Certified node distance \tau_s

The outcome tag determines how each integer payload is decoded:

d_{s,a}= \begin{cases} R_{s,a},&z_{s,a}=\bot,\\ \tau_{s,a},&z_{s,a}\ne\bot, \end{cases} \qquad d_s= \begin{cases} n_s,&z_s=\bot,\\ \tau_s,&z_s\ne\bot. \end{cases}

An unresolved node may have n_s=0, so zero alone cannot mean terminal once the slots are overlaid. The redundant terminal Boolean disappears, but the exact test is

\mathrm{terminal}(s) \iff z_s\ne\bot\ \land\ d_s=0.

This requires root evaluation to provide an exact terminal outcome whenever the root itself can be terminal. A Boolean terminal flag without its outcome is no longer a sufficient root contract.

2.1 Effective actions without duplicate posterior fields

While an edge is unresolved, its integer payload is a count and its float slot changes meaning in place:

A_{s,a}= \begin{cases} H_{s,a}=B_{s,a}, &z_{s,a}=\bot\ \land\ d_{s,a}>0,\\[3pt] \mathrm{Align}(V_{s_a};p_{s_a}\to p_s), &z_{s,a}=\bot\ \land\ d_{s,a}=0\ \land\ s_a\text{ exists},\\[3pt] H_{s,a}=Q_{s,a}, &z_{s,a}=\bot\ \land\ s_a\text{ does not exist}. \end{cases}

Thus Q and B are successive contents of one float slot, while A is computed and never stored. The fixed V_s and mutable C_s cannot share a slot while the node is unresolved: every repair needs both at the same time.

Policy logits are not tree state. Legality is extracted during evaluation and stored as a compact mask. Categorical ties use the search RNG directly, so they never trigger another network evaluation.

2.2 Safe integer-slot transitions

The node total is maintained incrementally. For every unresolved edge-count change r_{\mathrm{old}}\to r_{\mathrm{new}}, update

d_s\leftarrow d_s+r_{\mathrm{new}}-r_{\mathrm{old}} \qquad(z_s=\bot)

before writing the new edge payload. The tree never recomputes n_s by summing a mixture of counts and distances.

When a child becomes categorical, publication is ordered as one transaction:

\begin{aligned} r_{\mathrm{final}}&\leftarrow 1+n_{s_a},\\ d_s&\leftarrow d_s+r_{\mathrm{final}}-r_{\mathrm{old}},\\ z_{s,a}&\leftarrow \mathrm{Align}(z_{s_a};p_{s_a}\to p_s),\\ d_{s,a}&\leftarrow \tau_{s_a}+1. \end{aligned}

The first two lines preserve the child's final structural contribution in the unresolved parent. Only then may the edge count be overwritten by distance. Once z_{s,a}\ne\bot, that payload is never again read as a count.

When the node itself becomes categorical, first publish its final 1+n_s contribution to its unresolved parent using the same transaction. After that value is safe in the parent total, overwrite

z_s\leftarrow z_s^{\mathrm{cat}}, \qquad d_s\leftarrow\tau_s.

A terminal child is the base case: \tau_{s_a}=0, so its incoming edge receives distance one and contributes structural support one before the overwrite.

Information that really is discarded: after an edge becomes categorical, its individual R_{s,a} no longer exists. Root summaries report structural counts only for unresolved edges, and categorical Q rows use their explicit categorical weight. The node total preserves mixing support but cannot reconstruct historical per-edge counts.

2.3 Native categorical certificates

An action is still one of two logical objects even though its count and distance share storage:

Y_{s,a}= \begin{cases} \mathrm{Cat}(z_{s,a},d_{s,a}),&z_{s,a}\ne\bot,\\[3pt] \mathrm{Dir}(A_{s,a}),&z_{s,a}=\bot. \end{cases}

The categorical tag is exact and absorbing. A certified edge is pruned from traversal. One certified win solves a node; a draw or loss is proved only after every legal edge is categorical.

Certified wins choose a shortest winning edge and certified losses choose a longest losing edge. All certified draw edges are equivalent. Whenever more than one edge remains tied—including equal-distance win or loss edges—the engine samples uniformly among them with the existing search RNG. Policy logits, draw-distance preferences, and action order do not break categorical ties.

u_{\mathrm{cat}}(L)=-1, \qquad u_{\mathrm{cat}}(D)=0, \qquad u_{\mathrm{cat}}(W)=1.

3. One Thompson rule

At every node—root or internal—the same selector assigns one utility to each native action:

X(Y_{s,a})= \begin{cases} u_{\mathrm{cat}}(z_{s,a}),&z_{s,a}\ne\bot,\\[3pt] U(\phi_a),\quad \phi_a\sim\mathrm{Dirichlet}(A_{s,a}),&z_{s,a}=\bot, \end{cases}

and chooses the legal action with highest utility:

a^*=\arg\max_{a\in\mathcal A(s)}X(Y_{s,a}).

Repeating this same choice M times estimates the probability that each action is best:

\widehat\pi_M(a\mid s) = \frac1M \sum_{j=1}^{M} \mathbf 1\!\left[ a=\arg\max_b X(Y_{s,b})^{(j)} \right]. X(\mathrm{Cat}(z,\tau))=u_{\mathrm{cat}}(z), \qquad X(\mathrm{Dir}(A))=U(\phi),\quad \phi\sim\mathrm{Dirichlet}(A).

Traversal applies this rule only to unresolved edges; mixed policy readout compares exact categorical utility with sampled Dirichlet utility. Node repair and root readout use populations of the same selector. There is no second action-selection algorithm.

4. One simulation

Stage 1
Simulate

Thompson-sample at each node and follow existing children to an unexpanded, terminal, or depth-cutoff edge.

Stage 2
Expand

Step the environment and evaluate the child. Create a node only when the selected edge is new.

Stage 3
Repair

Walk from the deepest parent back to the root and update every node with the same posterior rule.

\text{simulation} = \text{traversal} \longrightarrow \text{leaf evaluation} \longrightarrow \text{bottom-up repair}.

4.1 Tagged leaf result

A non-terminal frontier contributes its complete network value prior:

L_{s'}=V_{s'}.

Expansion also returns one exact tag:

\mathrm{terminal\_outcome}(s')= \begin{cases} z_{s'},&s'\text{ is terminal},\\ \mathrm{NO\_OUTCOME},&s'\text{ is non-terminal}. \end{cases}

A terminal tag creates \mathrm{Cat}(z_{s'},0) on the child and the aligned distance-one certificate on its incoming edge. It does not create a terminal Dirichlet. Model alphas are used as unresolved leaf messages and caches only.

5. Bottom-up posterior repair

The default rule is local: it receives one node, all of its child summaries, and the final leaf only when this is the deepest path node.

Step A · write the final edge

At the deepest node s_d, an unresolved selected edge increments its structural count and replaces its alpha message:

R_{s_d,a_d}\leftarrow R_{s_d,a_d}+1, B_{s_d,a_d}\leftarrow \mathrm{Align}(V_{s'};p_{s'}\to p_{s_d}) \quad\text{only when }z_{s_d,a_d}=\bot.

B is replaced, not added. If expansion is terminal, the engine instead folds support one into n_{s_d} and overwrites the edge payload with distance one; the posterior callback never reads that distance as R.

Step B · refresh from children

For every expanded, unresolved child with repaired information below it, replace the parent edge by the child's current cache. Its node payload still means n_{s_a}:

B_{s,a} \leftarrow \mathrm{Align}(C_{s_a};p_{s_a}\to p_s), \qquad R_{s,a} \leftarrow 1+n_{s_a}, \quad n_{s_a}>0.

When a child becomes categorical, the engine first commits the final 1+n_{s_a} count delta to the parent total, then overwrites the incoming edge count with distance. Categorical children are never refreshed as Dirichlet messages afterwards.

Step C · form a fresh node policy

Recompute all effective action posteriors and estimate a fresh posterior-best policy:

\pi_s = \widehat\pi_{M_{\mathrm{node}}} (\,\cdot\mid s;Y_s).

This is not a visit distribution or a running average. It is a new mixed-native population: categorical utilities are exact and unresolved utilities are freshly Thompson-sampled.

Step D · repair the node value

While the node is unresolved, its node payload is the incrementally maintained total structural support

\gamma_s=\frac{n_s}{\kappa+n_s}.

The incremental form is necessary because categorical edge payloads now contain distance, not their discarded historical count.

For the numeric cache mixture only, preserve each categorical edge's learned effective-alpha mass but replace its direction by the exact sidecar outcome:

\widetilde A_{s,a}= \begin{cases} A_{s,a},&z_{s,a}=\bot,\\[3pt] \left(\sum_i A_{s,a,i}\right)e_{z_{s,a}},&z_{s,a}\ne\bot. \end{cases}

Average these cache operands with the fresh search policy:

\bar A_s = \sum_{a\in\mathcal A(s)} \pi_s(a)\widetilde A_{s,a}.

Then interpolate between the fixed network value and the repaired descendants:

\boxed{ C_s = (1-\gamma_s)V_s + \gamma_s\bar A_s }.

If n_s=0, then C_s=V_s. The sole constant \kappa>0 is the strength of that learned value prior against repaired descendants. It is not leaf evidence or terminal confidence. The categorical projection does not mutate A and never replaces the exact sidecar or categorical training target.

For the blend-only envelope of the unresolved numeric-cache channel, define g_d=\prod_{i=1}^{d}\gamma_i. If structural support were constant, n_i=n, this becomes

g_d=\left(\frac{n}{\kappa+n}\right)^d =\exp(-d/\ell), \qquad \ell(n,\kappa)=\frac{1}{\log(1+\kappa/n)}.

This is not yet the coefficient of one descendant edge. Holding each node-local policy fixed, a perturbation traveling along selected actions a_1,\ldots,a_d instead has branch coefficient

w_P^{\mathrm{fixed}} =\prod_{i=1}^{d}\gamma_i\pi_i(a_i) \leq g_d.

The policies themselves depend on repaired posteriors, so their Jacobians contribute to a full perturbation, and a rerun may even change topology. The logged product \prod_i\gamma_i is therefore a cache-mix attenuation envelope, not realized information transmission. The effective length describes only that envelope. It is not a reward horizon: exact terminal and solved outcomes propagate through categorical sidecars without this attenuation.

The local sensitivity makes the distinction precise. Let \Delta_s=\bar A_s-V_s. Holding the realized n_s,V_s,\bar A_s fixed,

C_s=V_s+\gamma_s\Delta_s, \qquad \left. \frac{\partial C_s}{\partial\log\kappa} \right|_{n_s,V_s,\bar A_s} =-\gamma_s(1-\gamma_s)\Delta_s, \qquad \left\| \frac{\partial C_s}{\partial\log\kappa} \right\|_2 \leq \frac14\|\bar A_s-V_s\|_2.

Because raw Dirichlet alpha distance mixes direction and mass, also let c_s=\mathbf 1^\top C_s, p_s=C_s/c_s, and G_s=\partial C_s/\partial\log\kappa. Then the exact local semantic and relative-concentration sensitivities are

\frac{\partial p_s}{\partial\log\kappa} = \frac{G_s-p_s(\mathbf 1^\top G_s)}{c_s}, \qquad \frac{\partial\log c_s}{\partial\log\kappa} = \frac{\mathbf 1^\top G_s}{c_s}.

A large change in \ell can therefore have little local effect for two different reasons: the mixture is saturated (n_s\ll\kappa or n_s\gg\kappa), or the learned prior already agrees with the repaired aggregate (\bar A_s\approx V_s). The latter is exactly the fixed point encouraged by search-based self-distillation: if \bar A_s=V_s, then C_s=V_s for every \kappa. This can indicate successful assimilation, but not correctness, because prior and search may share the same bias.

For a heterogeneous unresolved numeric path P, holding its supports fixed,

-\log g_P =\sum_{i\in P}-\log\gamma_i =\sum_{i\in P}\log\left(1+\frac{\kappa}{n_i}\right), \qquad \frac{\partial\log g_P}{\partial\log\kappa} =-\sum_{i\in P}(1-\gamma_i).

Thus the observed gamma product and its log attenuation are a more faithful blend-only envelope than a root-local constant-support \ell. Even a cache change must then reach a root edge posterior and cross a commitment boundary. Paired reruns, rather than this envelope, measure the deployed effect. If q_\kappa has unique top-two margin m_\kappa=q_{\kappa,(1)}-q_{\kappa,(2)}, a deterministic argmax can change only if

\|q_{\kappa'}-q_\kappa\|_\infty \geq \frac{m_\kappa}{2}.

For plurality commitment the margin remains diagnostic, but this hard condition does not apply because the finite vote is random. The implementation also reports the fraction of policies whose top-two margin is at most 1/M. That one-vote spacing is a descriptive reference scale for an M-sample empirical policy, not a decision threshold for argmax, plurality, or posterior sampling. Finally, an action flip need not change strength: it may select an outcome-equivalent move, occur on a rarely visited state, or be irrelevant against the chosen opponent. The direct final-edge message is also installed before the cache mix, and completed root action readout ranks root edge posteriors rather than the root's mixed value cache.

5.1 Why the order matters

For a selected path

s_0\to s_1\to\cdots\to s_d,

repair runs in the reverse order:

s_d,\ s_{d-1},\ \ldots,\ s_0.

When s_i is repaired, it therefore sees the new C_{s_{i+1}} computed moments earlier. This is how one local rule transports information all the way to the root.

6. Root readout and training targets

Search first completes the tree and constructs its native winner-count readout. At an unresolved root it is a fresh population of M native Thompson winners; the standard M=32 setting is abbreviated M32:

\pi_M^{\mathrm{nat}}(a\mid s_0) = \begin{cases} \widehat\pi_M(a\mid s_0;Y_{s_0}), &z_{s_0}=\bot,\\[3pt] e_{A_{\mathrm{cat}}}(a), &z_{s_0}\ne\bot. \end{cases} \qquad A_{\mathrm{cat}}\sim\mathrm{Uniform}(\mathcal B(s_0)).

Here \mathcal B(s_0) is the distance-optimal certified tie set: shortest wins, longest losses, or all certified draws. This native random tie-break, the native backend action, and the completed tree always exist before the optional readouts below.

Readout is not search: selecting a different completed-root target or commitment estimator does not rerun or mutate traversal, expansion, bottom-up repair, proof propagation, certificates, or the tree. A different committed action can change only the subsequent game trajectory.

6.1 Guarded target and commitment estimators

For an unresolved binary root, let x_a be action a's Beta-distributed win probability. Since binary utility is monotone in x_a, the population probability that a is best is

q_a^\star =\Pr(x_a=\max_b x_b) =\int_0^1 f_a(x)\prod_{b\ne a}F_b(x)\,dx.

The adaptive prefix-CDF estimator approximates all these integrals together on Q=2h+1 sinh-logit grid points; Q21 is h=10. Prefix sums produce every CDF, and each increment of the maximum CDF is distributed among actions by its local nonnegative winner contribution. This is permutation equivariant, costs O(AQ), and conserves policy mass up to roundoff.

T=\mathrm{clip}\left( \mathrm{asinh}\left( \frac{\mathrm{tail\_scale}} {\min_{a:\,z_{s_0,a}=\bot,\ z}\alpha_{a,z}} \right), T_{\min},T_{\max} \right).

An unresolved root accepts the estimate only when the adaptive tail range is not clipped, all values are finite, and the maximum absolute pre-normalization log density-integral error is at most 0.01. An unsafe lane falls back to its already computed native M32 policy; safe lanes in the same batch remain usable. Prefix-CDF root readout is binary-only.

root_policy_target_estimator and root_action_estimator independently choose winner_mc or prefix_cdf; both default to winner_mc. If either requests prefix-CDF, one quadrature is computed and shared. These root fields are separate from posterior_policy_estimator, which controls node-local cache repair while the tree is being built. Define the exact solved population

\pi^{\mathrm{cat}}(a\mid s_0) =\frac{\mathbf 1[a\in\mathcal B(s_0)]}{|\mathcal B(s_0)|}.

Training target

winner_mc stores \pi_M^{\mathrm{nat}}. Safe prefix mode stores \widetilde q_Q at an unresolved root and \pi^{\mathrm{cat}} at a solved root; an unsafe unresolved root stores native M32.

Action commitment

Safe prefix mode supplies \widetilde q_Q only to unresolved-root posterior_argmax, posterior_plurality, or posterior_sample. The last mode draws from its configured power-temperature transform. Solved commitment stays the native random distance-optimal one-hot. search_action always stays native.

The commitment policy is ephemeral and is not copied into replay. The Q and V targets retain the native tagged objects used by the completed search:

T^Q_{s,a}= \begin{cases} \mathrm{Pad},&a\text{ illegal},\\ \mathrm{Cat}(z_{s,a},\tau_{s,a}),&z_{s,a}\ne\bot,\\ \mathrm{Dir}(A_{s,a}),&z_{s,a}=\bot, \end{cases} T^V_s= \begin{cases} \mathrm{Cat}(z_s,\tau_s),&z_s\ne\bot,\\ \mathrm{Dir}(C_s),&z_s=\bot. \end{cases}

Structural counts, these Q/V targets, and the policy-mode Q-loss weight all remain native. In particular, policy-mode Q reduction uses \pi_M^{\mathrm{nat}}, never the optional policy target or commitment policy. There is no root-only reconstruction \beta_Q=\alpha_{\mathrm{base}}+E_Q, and R is never added to Dirichlet concentration.

6.2 Finite-population plurality commitment

posterior_plurality draws M= posterior_plurality_samples categorical votes from the legal commitment population (default 32), then commits the lowest-index action among the largest counts:

A_M=\min\arg\max_a C_a, \qquad [g_M(q)]_a =\sum_{\substack{c\in\mathbb N^L,\ \sum_i c_i=M\\ c_a>c_j\ (j<a),\ c_a\ge c_j\ (j>a)}} \frac{M!}{\prod_i c_i!}\prod_i q_i^{c_i}.

This finite-population operator satisfies g_1(q)=q and converges to the deterministic mode when that mode is unique. It is not a temperature transform; at finite M, count ties preserve the stated lowest-index bias.

The implementation zeros illegal, non-finite, and non-positive entries and renormalizes before drawing. Zero legal mass falls back to the uniform legal population, with action zero as the no-legal-action sentinel. Exact one-hot policies bypass resampling.

Conditional on one fixed, completed, unresolved tree T, let q^{\mathrm{impl}}(T) be the winner distribution of one production Thompson draw. Native winner-MC produces C=M\pi_M^{\mathrm{nat}}\sim\mathrm{Multinomial}(M,q^{\mathrm{impl}}(T)), hence

\mathcal L\!\left( \min\arg\max_a\pi_M^{\mathrm{nat}}(a)\mid T \right) =g_M\!\left(q^{\mathrm{impl}}(T)\right).

Accordingly, accepted Q21 followed by plurality-32 has law g_{32}(\widetilde q_{21}(T)). It exactly matches native M32 plus posterior_argmax only if \widetilde q_{21}=q^{\mathrm{impl}} and both use the same count-tie rule. Q21 quadrature error and the native Gamma sampler's rare bounded-work bias relative to the ideal q^\star must remain distinct. If the Q21 guard fails, plurality bypasses its new vote draw and returns the native histogram's lowest-index argmax. Explicitly applying K plurality votes to a winner-MC histogram would instead have conditional law g_K(\pi_M^{\mathrm{nat}}) and is a two-stage transform. Solved roots also remain outside plurality: their exact one-hot policies preserve the native uniformly sampled distance-optimal categorical action.

Why the intermediate transform matters: sampling q directly is the M=1 endpoint and can turn a broad epistemic posterior into overly diffuse behavior. Taking \arg\max q discards every margin, is discontinuous at ties, and can amplify small asymmetries into collapsed coverage. Finite g_M aggregates repeated winner draws while retaining controlled randomness; away from close count ties its unique-mode concentration suppresses low-mass alternatives. The equality above is conditional on the same tree only; different committed actions produce different later states, trees, training data, and eventually weights.

6.3 Power-temperature posterior sampling

For a nonempty legal set, posterior_sample uses T= posterior_sample_temperature and \epsilon=10^{-8}:

\bar q_a =\mathbf 1[a\in\mathcal A_{\mathrm{legal}}]\, \mathrm{clip}(q_a,\epsilon,1), \qquad [\tau_T(q)]_a =\frac{\bar q_a^{1/T}} {\sum_{b\in\mathcal A_{\mathrm{legal}}}\bar q_b^{1/T}}, \qquad T>0.

At T=1 this is exactly the existing direct sampler, including its numerical floor. If the floored legal population has a unique maximizer a^\star, then \tau_T(q)\to e_{a^\star} as T\downarrow0. This is an ephemeral commitment transform only: it does not alter traversal, repair, the completed tree, policy or Q/V targets, replay, or the current search weights.

\frac{[\tau_T(q)]_a}{[\tau_T(q)]_b} = \left( \frac{\mathrm{clip}(q_a,\epsilon,1)} {\mathrm{clip}(q_b,\epsilon,1)} \right)^{1/T}.

Therefore temperature preserves the clipped weak ranking—strictly unless the floor collapses two coordinates—and satisfies IIA because the odds of a against b do not depend on another action. Finite plurality does neither under the production lowest-index count-tie rule. For every finite M\ge2 with at least three full-support actions, a symmetric population has positive-probability maximum-count ties; choosing the lowest index breaks permutation symmetry and, by continuity, creates nearby rank reversals. Writing \Phi_M=g_M, the concrete two-vote law is

[\Phi_2(q)]_0=2q_0-q_0^2, \qquad [\Phi_2(q)]_1=q_1^2+2q_1q_2.

For q=(0.34,0.35,0.31), the input ranks action 1 above action 0, but [\Phi_2(q)]_0=0.5644>0.3395=[\Phi_2(q)]_1. Along q=(x,x,1-2x), their output odds are (2-x)/(2-3x), which change with the third coordinate although q_0/q_1=1. The same finite maximum-count ties create literal lowest-index bias.

Intervention, not equivalence: temperature sampling can replace plurality as a simpler one-parameter causal intervention while holding the completed tree and commitment population fixed. It is not an exact law-equivalent substitution for multiclass \Phi_M; matching entropy, top-action mass, or game strength does not make the action distributions identical, and a temperature fitted at one root is not an identity at other roots. Unsafe prefix-CDF action lanes, and solved roots whose action readout requested prefix-CDF, bypass both stochastic rereadouts and preserve the native commitment argmax exactly.

6.4 Losses and target-induced gradient error

The policy head distills the independently selected policy target:

\mathcal L_\pi(q) =-\sum_{a\in\mathcal A(s)}q_a\log p_{\theta,a}, \qquad \nabla_r\mathcal L_\pi(q)=p_\theta-q.

Consequently target error is exactly policy-logit-gradient error:

\nabla_r\mathcal L_\pi(\widetilde q) -\nabla_r\mathcal L_\pi(q) =q-\widetilde q, \qquad \|\Delta\nabla_r\mathcal L_\pi\|_2^2 =\|\widetilde q-q\|_2^2.

For M independent winner draws, let q^{\mathrm{impl}} be the winner distribution induced by the production sampling primitive. The native unresolved policy is a multinomial proportion:

M\widehat q_M \sim\mathrm{Multinomial}(M,q^{\mathrm{impl}}), \qquad \mathrm{Cov}(\widehat q_M) =\frac{ \mathrm{Diag}(q^{\mathrm{impl}}) -q^{\mathrm{impl}}(q^{\mathrm{impl}})^\top }{M}, \qquad \mathbb E\|\widehat q_M-q^{\mathrm{impl}}\|_2^2 =\frac{1-\|q^{\mathrm{impl}}\|_2^2}{M}.

This finite-M target MSE is also its expected squared logit-gradient error relative to the implemented population. The production Gamma sampler's rare bounded-work fallback can add bias relative to the ideal exact-Beta population. Prefix quadrature trades sampling variance for deterministic discretization bias, so both must be checked against a high-precision exact-Beta reference.

Full Dirichlet training matches both mean and concentration:

\mathcal L_{\mathrm{full}}(\beta,\alpha_\theta) = D_{\mathrm{KL}} \left( \mathrm{Dirichlet}(\mathrm{stopgrad}\beta) \,\|\, \mathrm{Dirichlet}(\alpha_\theta) \right).

Mean-only training ignores concentration and matches normalized outcome probabilities:

\mathcal L_{\mathrm{mean}}(\beta,\alpha_\theta) = D_{\mathrm{KL}} \left( \mathrm{stopgrad}\mu(\beta) \,\|\, \mu(\alpha_\theta) \right).

For an exact categorical outcome z, move the point just inside the simplex and train the predicted Dirichlet by density likelihood:

\phi_z^\epsilon =(1-K\epsilon)e_z+\epsilon\mathbf 1, \qquad \mathcal L_{\mathrm{cat}}(\alpha_\theta,z) =-\log p_{\mathrm{Dirichlet}(\alpha_\theta)} (\phi_z^\epsilon).

Thus unresolved rows use full or mean Dirichlet matching, while categorical rows use this exact-outcome density loss in either mode. The concentration is learned by the model; no terminal concentration constant is injected by search.

For an unresolved Q target, the loss can be weighted by native structural support or native root policy. A categorical row no longer owns an R value and receives an explicit unit categorical weight:

w_a= \begin{cases} R_{s_0,a}, &z_{s_0,a}=\bot\ \text{and evidence-mass mode},\\ \pi_M^{\mathrm{nat}}(a\mid s_0), &z_{s_0,a}=\bot\ \text{and policy mode},\\ 1,&z_{s_0,a}\ne\bot. \end{cases}

6.4 Measuring information transfer

For one fixed target, cross-entropy minus target entropy is a measurable displacement in nats:

\mathrm{CE}(q,p_\theta)-H(q) =D_{\mathrm{KL}}(q\|p_\theta).

To measure how much of that discrepancy enters the weights, evaluate the same target, legal mask, and probe population before and after an update window:

\Delta_{\mathrm{capture}} =D_{\mathrm{before}}-D_{\mathrm{after}}, \qquad f_{\mathrm{capture}} =\frac{D_{\mathrm{before}}-D_{\mathrm{after}}} {D_{\mathrm{before}}}.

Positive capture means the fixed-target gap shrank; negative capture means it grew. Always log the raw before/after gaps, their difference, and both population counts alongside the fraction. The fraction is unstable for a tiny initial gap and is undefined if the compared populations differ.

Useful companion measurements are V/Q semantic and full-Dirichlet capture, loss-weighted Q capture, target entropy/support/effective sample size, every prefix guard and fallback rate, L1 and squared-L2 distance from native M32, and top-one agreement. These diagnose target production and assimilation, but they do not prove game strength.

A flat arena response should be localized through the full causal funnel. At numeric repairs, report raw innovation \|\bar A-V\|_2, normalized semantic innovation, concentration innovation, and the raw-alpha, normalized-mean, and relative-concentration derivatives with respect to \log\kappa. Along completed unresolved numeric paths, report the blend-envelope quantities \prod_i\gamma_i and \sum_i-\log\gamma_i, together with categorical and solved bypass rates. At the root, report paired policy distance, top-two margin, top-action flips, and occupancy-weighted exact-oracle regret. Means should be accompanied by stage/support strata and upper quantiles so rare decisive states are not averaged away. Only after these measurements should seat-balanced pairwise games be summarized; one opponent or a one-dimensional Elo projection cannot identify a global strength effect in a non-transitive league.

Interpretation: search displacement is target-prior discrepancy, not Bayesian information gain or mutual information. M32 disagreement is not accuracy because M32 is noisy. Capture on a fixed probe does not measure later retention or assign causal credit among simultaneous losses. Arena, seat-stratified, and exact-oracle metrics remain separate.

7. Simulations are not tree size

With num_simulations = N, search allocates N static iterations and performs at most N active traversal–evaluation–repair cycles on one persistent tree:

\mathcal T_0 \xrightarrow{\text{simulation }1} \mathcal T_1 \xrightarrow{\text{simulation }2} \cdots \xrightarrow{\text{simulation }N} \mathcal T_N.

JAX allocates a static upper bound of one possible new node per simulation, plus the root:

N_{\mathrm{slots}}=N+1.

A revisit or depth cutoff still evaluates and repairs the path but does not initialize a new node. Therefore

N_{\mathrm{real\ nodes}}\le N+1.

The fixed array is capacity, not a requirement to fill every slot. Once the root is categorical, later static iterations are inactive and do not call expansion. max_depth separately limits one traversal's length.

8. The replaceable part

The tree-search engine owns traversal, exact terminal tags, categorical sidecars, proof propagation, storage, and bottom-up order. The posterior callback owns unresolved Dirichlet repair and the cache mixture:

\mathcal F_{\mathrm{posterior}}: (\text{key},\ \text{node},\ \text{children},\ \text{leaf}) \longmapsto (H_s,\ d_s^{\mathrm{edge}},\ C_s).

It is called once for every node on the selected path and returns an ephemeral update; the persistent tree remains flat. A different rule can inspect the current node embedding and all child summaries, then replace unresolved alphas, counts, and the node cache without changing traversal. The engine owns count-delta accounting and categorical payload transitions. The default callback exposes its single prior-strength choice as \kappa in \gamma=n/(\kappa+n).
