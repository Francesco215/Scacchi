Dirichlet Thompson Tree Search

A math-first explanation of Scacchi's lightweight tree, its bottom-up message passing, and the targets returned to the network.

The search represents unresolved state and action values as learned Dirichlet beliefs over loss, draw, and win. Exact terminal and solved results live in categorical outcome/distance sidecars. A simulation walks unresolved edges by Thompson sampling, evaluates one frontier edge, and repairs every node on the path back to the root.

The central idea: an unresolved edge stores the latest repaired Dirichlet message; it does not keep adding leaf evidence. A separate structural count controls prior mixing. Once an edge is categorical, its exact sidecar—not an artificially concentrated alpha—owns its semantics.

1. Network beliefs

At state s, the network predicts a policy together with one state Dirichlet and one Dirichlet for every action:

\pi_\theta(a\mid s), \qquad V_s=\alpha_\theta^V(s), \qquad Q_{s,a}=\alpha_\theta^Q(s,a).

A Dirichlet parameter vector \alpha represents uncertainty about an outcome distribution:

\phi\sim\mathrm{Dirichlet}(\alpha), \qquad \mu(\alpha)=\mathbb E[\phi] =\frac{\alpha}{\sum_z\alpha_z}.

The outcomes are ordered as (L,W) or (L,D,W). Search compares samples with the same utility everywhere:

U(\phi)=\phi_W-\phi_L.

1.1 Player perspective

Values belong to the player to move at their node. Moving a value to the opponent's perspective reverses loss and win:

\mathrm{flip}(x_L,x_D,x_W) =(x_W,x_D,x_L). \mathrm{Align}(x;p\to q)= \begin{cases} x,&p=q,\\ \mathrm{flip}(x),&p\ne q. \end{cases}

Every child-to-parent message is aligned before it is stored.

2. What the tree remembers

The tree separates network priors, mutable messages, and structural counts:

Symbol Meaning Role
V_s Network value prior Fixed anchor for node s
Q_{s,a} Network action prior Fallback before the edge has information
B_{s,a} Edge message Latest leaf or repaired-child Dirichlet
R_{s,a} Structural count Marks a message and measures repaired depth below it
C_s Node cache Current repaired state Dirichlet
A_{s,a} Effective unresolved edge alpha Message, child-value prior, or Q fallback
(z_{s,a},\tau_{s,a}) Exact categorical edge certificate Outcome and certified distance; z=\bot means unresolved
(z_s,\tau_s) Exact categorical node certificate Absorbing solved value derived from edge certificates

Initially, C_s=V_s and the edge slot contains the Q fallback. A real message is present exactly when

m_{s,a}=\mathbf 1[R_{s,a}>0].

2.1 Effective edge posterior

For an expanded child s_a, the Dirichlet used by search is

A_{s,a}= \begin{cases} B_{s,a}, & R_{s,a}>0,\\[3pt] \mathrm{Align}(V_{s_a};p_{s_a}\to p_s), & R_{s,a}=0\ \text{and }s_a\text{ exists},\\[3pt] Q_{s,a}, & \text{otherwise}. \end{cases}

Expanded but unrepaired

Use the child's fixed value prior V_{s_a}.

Child has downstream information

Its repaired cache is promoted into B_{s,a}.

Neither R nor a visit count is added to A. Its concentration remains learned through the network alphas and repaired messages.

2.2 Native categorical certificates

An action is one of two native objects:

Y_{s,a}= \begin{cases} \mathrm{Cat}(z_{s,a},\tau_{s,a}),&z_{s,a}\ne\bot,\\[3pt] \mathrm{Dir}(A_{s,a}),&z_{s,a}=\bot. \end{cases}

A terminal child has distance zero and its incoming edge has distance one. The certificates are exact, absorbing, and stored separately from every alpha. A certified edge is pruned from later traversal. One certified win solves a node; a draw or loss is proved only after every legal edge is categorical.

u_{\mathrm{cat}}(L)=-1, \qquad u_{\mathrm{cat}}(D)=0, \qquad u_{\mathrm{cat}}(W)=1.

3. One Thompson rule

At every node—root or internal—the same selector assigns one utility to each native action:

X(Y_{s,a})= \begin{cases} u_{\mathrm{cat}}(z_{s,a}),&z_{s,a}\ne\bot,\\[3pt] U(\phi_a),\quad \phi_a\sim\mathrm{Dirichlet}(A_{s,a}),&z_{s,a}=\bot, \end{cases}

and chooses the legal action with highest utility:

a^*=\arg\max_{a\in\mathcal A(s)}X(Y_{s,a}).

Repeating this same choice M times estimates the probability that each action is best:

\widehat\pi_M(a\mid s) = \frac1M \sum_{j=1}^{M} \mathbf 1\!\left[ a=\arg\max_b X(Y_{s,b})^{(j)} \right]. X(\mathrm{Cat}(z,\tau))=u_{\mathrm{cat}}(z), \qquad X(\mathrm{Dir}(A))=U(\phi),\quad \phi\sim\mathrm{Dirichlet}(A).

Traversal applies this rule only to unresolved edges; mixed policy readout compares exact categorical utility with sampled Dirichlet utility. Node repair and root readout use populations of the same selector. There is no second action-selection algorithm.

4. One simulation

Stage 1
Simulate

Thompson-sample at each node and follow existing children to an unexpanded, terminal, or depth-cutoff edge.

Stage 2
Expand

Step the environment and evaluate the child. Create a node only when the selected edge is new.

Stage 3
Repair

Walk from the deepest parent back to the root and update every node with the same posterior rule.

\text{simulation} = \text{traversal} \longrightarrow \text{leaf evaluation} \longrightarrow \text{bottom-up repair}.

4.1 Tagged leaf result

A non-terminal frontier contributes its complete network value prior:

L_{s'}=V_{s'}.

Expansion also returns one exact tag:

\mathrm{terminal\_outcome}(s')= \begin{cases} z_{s'},&s'\text{ is terminal},\\ \mathrm{NO\_OUTCOME},&s'\text{ is non-terminal}. \end{cases}

A terminal tag creates \mathrm{Cat}(z_{s'},0) on the child and the aligned distance-one certificate on its incoming edge. It does not create a terminal Dirichlet. Model alphas are used as unresolved leaf messages and caches only.

5. Bottom-up posterior repair

The default rule is local: it receives one node, all of its child summaries, and the final leaf only when this is the deepest path node.

Step A · write the final edge

At the deepest node s_d, increment the selected edge's structural count. Replace its alpha message only if the edge is still unresolved:

R_{s_d,a_d}\leftarrow R_{s_d,a_d}+1, B_{s_d,a_d}\leftarrow \mathrm{Align}(V_{s'};p_{s'}\to p_{s_d}) \quad\text{only when }z_{s_d,a_d}=\bot.

B is replaced, not added. A terminal edge keeps its exact sidecar and does not overwrite B with a synthetic alpha.

Step B · refresh from children

For every expanded, non-terminal child with repaired information below it, replace the parent edge by the child's current cache:

n_{s_a} = \sum_{b\in\mathcal A(s_a)}R_{s_a,b}. B_{s,a} \leftarrow \mathrm{Align}(C_{s_a};p_{s_a}\to p_s), \qquad R_{s,a} \leftarrow 1+n_{s_a}, \quad n_{s_a}>0.

Categorical children are not refreshed this way; their exact outcome/distance already lives on the edge sidecar.

Step C · form a fresh node policy

Recompute all effective action posteriors and estimate a fresh posterior-best policy:

\pi_s = \widehat\pi_{M_{\mathrm{node}}} (\,\cdot\mid s;Y_s).

This is not a visit distribution or a running average. It is a new mixed-native population: categorical utilities are exact and unresolved utilities are freshly Thompson-sampled.

Step D · repair the node value

Let the total structural support below the node be

n_s=\sum_{a\in\mathcal A(s)}R_{s,a}, \qquad \gamma_s=\frac{n_s}{\kappa+n_s}.

For the numeric cache mixture only, preserve each categorical edge's learned effective-alpha mass but replace its direction by the exact sidecar outcome:

\widetilde A_{s,a}= \begin{cases} A_{s,a},&z_{s,a}=\bot,\\[3pt] \left(\sum_i A_{s,a,i}\right)e_{z_{s,a}},&z_{s,a}\ne\bot. \end{cases}

Average these cache operands with the fresh search policy:

\bar A_s = \sum_{a\in\mathcal A(s)} \pi_s(a)\widetilde A_{s,a}.

Then interpolate between the fixed network value and the repaired descendants:

\boxed{ C_s = (1-\gamma_s)V_s + \gamma_s\bar A_s }.

If n_s=0, then C_s=V_s. The sole constant \kappa>0 is the strength of that learned value prior against repaired descendants. It is not leaf evidence or terminal confidence. The categorical projection does not mutate A and never replaces the exact sidecar or categorical training target.

5.1 Why the order matters

For a selected path

s_0\to s_1\to\cdots\to s_d,

repair runs in the reverse order:

s_d,\ s_{d-1},\ \ldots,\ s_0.

When s_i is repaired, it therefore sees the new C_{s_{i+1}} computed moments earlier. This is how one local rule transports information all the way to the root.

6. Root readout and training targets

If the root remains unresolved, its policy is another mixed-native posterior-best population. If the root is categorical, the policy is one-hot on its certified action:

\pi_{\mathrm{search}}(a\mid s_0) = \begin{cases} \widehat\pi_{M_{\mathrm{root}}}(a\mid s_0;Y_{s_0}), &z_{s_0}=\bot,\\[3pt] \mathbf 1[a=a_{\mathrm{cat}}(s_0)], &z_{s_0}\ne\bot. \end{cases}

The Q and V targets retain the same native tags used by search:

T^Q_{s,a}= \begin{cases} \mathrm{Pad},&a\text{ illegal},\\ \mathrm{Cat}(z_{s,a},\tau_{s,a}),&z_{s,a}\ne\bot,\\ \mathrm{Dir}(A_{s,a}),&z_{s,a}=\bot, \end{cases} T^V_s= \begin{cases} \mathrm{Cat}(z_s,\tau_s),&z_s\ne\bot,\\ \mathrm{Dir}(C_s),&z_s=\bot. \end{cases} \pi_{\mathrm{target}}(a\mid s_0) = \pi_{\mathrm{search}}(a\mid s_0).

There is no root-only reconstruction \beta_Q=\alpha_{\mathrm{base}}+E_Q, and R is never added to Dirichlet concentration. A categorical target consumes the exact sidecar, not the numeric cache projection.

6.1 Losses

The policy head distills the posterior-best distribution:

\mathcal L_\pi = -\sum_{a\in\mathcal A(s)} \mathrm{stopgrad}(\pi_{\mathrm{target}}(a\mid s)) \log\pi_\theta(a\mid s).

Full Dirichlet training matches both mean and concentration:

\mathcal L_{\mathrm{full}}(\beta,\alpha_\theta) = D_{\mathrm{KL}} \left( \mathrm{Dirichlet}(\mathrm{stopgrad}\beta) \,\|\, \mathrm{Dirichlet}(\alpha_\theta) \right).

Mean-only training ignores concentration and matches normalized outcome probabilities:

\mathcal L_{\mathrm{mean}}(\beta,\alpha_\theta) = D_{\mathrm{KL}} \left( \mathrm{stopgrad}\mu(\beta) \,\|\, \mu(\alpha_\theta) \right).

For an exact categorical outcome z, move the point just inside the simplex and train the predicted Dirichlet by density likelihood:

\phi_z^\epsilon =(1-K\epsilon)e_z+\epsilon\mathbf 1, \qquad \mathcal L_{\mathrm{cat}}(\alpha_\theta,z) =-\log p_{\mathrm{Dirichlet}(\alpha_\theta)} (\phi_z^\epsilon).

Thus unresolved rows use full or mean Dirichlet matching, while categorical rows use this exact-outcome density loss in either mode. The concentration is learned by the model; no terminal concentration constant is injected by search.

The Q loss can be weighted by structural support or by root policy:

w_a= \begin{cases} R_{s_0,a}, &\text{structural/evidence-mass mode},\\ \pi_{\mathrm{search}}(a\mid s_0), &\text{policy mode}. \end{cases}

7. Simulations are not tree size

With num_simulations = N, search allocates N static iterations and performs at most N active traversal–evaluation–repair cycles on one persistent tree:

\mathcal T_0 \xrightarrow{\text{simulation }1} \mathcal T_1 \xrightarrow{\text{simulation }2} \cdots \xrightarrow{\text{simulation }N} \mathcal T_N.

JAX allocates a static upper bound of one possible new node per simulation, plus the root:

N_{\mathrm{slots}}=N+1.

A revisit or depth cutoff still evaluates and repairs the path but does not initialize a new node. Therefore

N_{\mathrm{real\ nodes}}\le N+1.

The fixed array is capacity, not a requirement to fill every slot. Once the root is categorical, later static iterations are inactive and do not call expansion. max_depth separately limits one traversal's length.

8. The replaceable part

The tree-search engine owns traversal, exact terminal tags, categorical sidecars, proof propagation, storage, and bottom-up order. The posterior callback owns unresolved Dirichlet repair and the cache mixture:

\mathcal F_{\mathrm{posterior}}: (\text{key},\ \text{node},\ \text{children},\ \text{leaf}) \longmapsto (B_s,\ R_s,\ C_s).

It is called once for every node on the selected path. A different rule can inspect the current node embedding and all child summaries, then return a complete replacement posterior without changing traversal or the public search API. The default callback exposes its single prior-strength choice as \kappa in \gamma=n/(\kappa+n); exact categorical semantics remain search-owned.
